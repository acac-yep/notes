    算法基础速通笔记¶

    目标：只阅读本文件，建立对当前这几份讲义所覆盖内容的完整知识框架，并能够独立完成常见的复杂度分析、递归式求解、排序算法比较、线性时间排序和顺序统计量题目。

    整理范围：课程 Topic 0、Topic 1、Topic 2、Topic 3、Topic 4.1、Topic 4.2，以及《Introduction to Algorithms》第 3 版中第 1--9 章与上述主题直接相关的内容。

    学习顺序：先看“总览与结论”，再看算法模板和证明套路，最后做文末的自测清单。文中的伪代码统一采用教材常见的 1 下标写法。

    0. 一页总览：这门课到底在学什么¶

    算法基础的核心不是背一堆算法，而是掌握下面四件事：

    1. 把问题说清楚：输入是什么，输出是什么，约束是什么。
    2. 设计一个可执行的过程：算法每一步做什么，为什么能得到正确答案。
    3. 证明它确实正确：循环不变量、归纳法、分治结构、概率分析。
    4. 分析资源消耗：时间复杂度、空间复杂度、最坏情况、平均情况和期望复杂度。

    整门课的主线可以压缩成：

    问题建模
   -> 正确性
   -> 复杂度
   -> 选择合适的算法范式
   -> 根据数据特征和约束做取舍

    当前材料重点覆盖的知识链：

    基本算法分析
  -> 渐进记号
  -> 分治与递归式
  -> 比较排序
  -> 比较排序下界
  -> 利用输入结构突破 n log n
  -> 顺序统计量与选择

    最重要的复杂度阶从快到慢大致是：

    O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)

    当 n 足够大时，低阶复杂度通常更重要。但真实选择还要看：

    • 是否需要稳定排序；
    • 是否允许额外空间；
    • 输入值是否有范围、位数或分布假设；
    • 是否要求最坏情况保证；
    • 常数、缓存、I/O 和实现复杂度是否重要。

    1. 基本概念：算法、正确性与分析¶

    1.1 什么是排序问题¶

    给定长度为 n 的序列：

    A = <a1, a2, ..., an>

    输出它的一个排列：

    <a'1, a'2, ..., a'n>

    使得：

    a'1 <= a'2 <= ... <= a'n

    注意“输出是输入的排列”意味着：

    • 元素不能凭空增加或消失；
    • 相同键对应的记录仍然都要保留；
    • 如果元素是记录，排序通常只比较某个 key，而不是整个记录。

    1.2 正确性比速度更优先¶

    算法分析不仅关注运行时间，还关注：

    • correctness：输出满足问题定义；
    • functionality：功能完整；
    • reliability / robustness：异常输入下行为合理；
    • modularity / maintainability：容易理解和修改；
    • simplicity：不引入不必要的复杂性。

    一个更快但不正确的算法没有意义。做题时建议按以下顺序写：

    先说明算法做什么
再说明为什么正确
最后分析复杂度

    1.3 循环不变量：证明迭代算法正确的标准模板¶

    循环不变量是一个在循环过程中始终保持为真的命题。标准证明分三步：

    初始化 Initialization¶

    第一次循环开始前，不变量成立。

    保持 Maintenance¶

    假设某次循环开始前不变量成立，证明执行一次循环后，下一次循环开始前仍成立。

    终止 Termination¶

    循环结束时，不变量和终止条件共同推出算法满足目标。

    记忆方式：

    初始化：一开始对不对？
保持：做一步之后还对不对？
终止：结束时这个性质能不能直接推出答案？

    插入排序的典型不变量：在外层循环处理下标 j 时，子数组 A[1..j-1] 已经有序，并且包含原来这部分的所有元素。

    1.4 输入规模和成本模型¶

    算法的运行时间应写成输入规模 n 的函数 T(n)。这里的 n 不一定是数组长度，必须根据问题定义选择合适的规模，例如：

    • 数组问题：元素个数；
    • 图问题：顶点数 V 和边数 E；
    • 大整数问题：二进制位数；
    • 矩阵问题：行数、列数或元素总数。

    通常先采用 RAM 模型，认为以下基本操作耗时 O(1)：

    • 加减乘除；
    • 读写数组元素；
    • 赋值、比较、分支、函数调用。

    这是一个抽象模型，重点是比较算法随规模增长的速度，而不是绑定某一台机器的绝对秒数。

    1.5 最坏、平均、最好和期望情况¶

    最坏情况¶

    T_worst(n) = 所有规模为 n 的输入中，运行时间的最大值

    最常用，因为它给出确定性保证。

    最好情况¶

    T_best(n) = 所有规模为 n 的输入中，运行时间的最小值

    只看最好情况通常没有指导意义，因为它可能掩盖算法在一般输入上的糟糕表现。

    平均情况¶

    需要先指定输入分布，再计算所有输入上的平均运行时间。没有输入分布，“平均复杂度”通常没有定义。

    期望复杂度¶

    随机算法中，对算法内部随机选择取期望。随机快速选择的期望线性时间就是这种分析。

    1.6 渐进分析的核心思想¶

    当 n -> infinity 时，忽略：

    • 机器相关的常数；
    • 低阶项；
    • 对增长速度没有影响的常数因子。

    例如：

    3n^3 + 90n^2 - 5n + 2006 = Theta(n^3)

    渐进分析的结论不是“所有情况下都更快”，而是“当规模足够大时，增长速度更慢”。小规模时，常数和实现细节可能改变实际表现。

    2. 渐进记号：O、Omega、Theta 以及比较函数¶

    2.1 三个最重要的记号¶

    O(g(n))：渐进上界¶

    若存在常数 c > 0 和 n0 > 0，使得当 n >= n0 时：

    0 <= f(n) <= c g(n)

    则称：

    f(n) = O(g(n))

    直觉：f 的增长速度不超过 g 的常数倍。

    注意：

    n = O(n^2)

    是正确的，但不够紧；如果能证明 Theta(n)，就不要只写 O(n^2)。

    Omega(g(n))：渐进下界¶

    若存在常数 c > 0 和 n0 > 0，使得当 n >= n0 时：

    0 <= c g(n) <= f(n)

    则称：

    f(n) = Omega(g(n))

    直觉：f 至少和 g 一样快地增长。

    Theta(g(n))：渐进紧确界¶

    若同时有：

    f(n) = O(g(n))
f(n) = Omega(g(n))

    则：

    f(n) = Theta(g(n))

    形式化地说，存在正常数 c1, c2, n0，使得：

    0 <= c1 g(n) <= f(n) <= c2 g(n),  n >= n0

    2.2 小写 o 和 omega¶

    它们表示严格的增长关系：

    f(n) = o(g(n))      表示 f 比 g 增长严格更慢
f(n) = omega(g(n))  表示 f 比 g 增长严格更快

    常用极限判定：

    lim f(n)/g(n) = 0       => f(n) = o(g(n))
lim f(n)/g(n) = infinity => f(n) = omega(g(n))

    例如：

    log^k n = o(n^epsilon)       任意常数 k，epsilon > 0
n^b = o(a^n)                 任意 a > 1，任意常数 b

    2.3 常用运算性质¶

    如果 f = Theta(g) 且 g = Theta(h)，那么：

    f = Theta(h)

    如果：

    f = O(g),  g = O(h)

    那么：

    f = O(h)

    常用“取主项”规则：

    Theta(f(n) + g(n)) = Theta(max(f(n), g(n)))

    前提是 f、g 最终非负。

    2.4 复杂度比较的常见结论¶

    记住以下增长顺序：

    1
log n
sqrt(n)
n
n log n
n^2
n^3
2^n
n!

    常用技巧：

    • 对数底数只差常数：log_a n = Theta(log_b n)；
    • 多项式中只看最高次项：n^3 + n^2 + n = Theta(n^3)；
    • 指数最终超过任何多项式：n^100 = o(2^n)；
    • 阶乘最终超过任何固定底数的指数：2^n = o(n!)；
    • log log n 比 log n 慢；
    • n log n 比 n^2 慢。

    2.5 常用求和¶

    等差型¶

    1 + 2 + ... + n = n(n+1)/2 = Theta(n^2)

    几何型¶

    1 + x + x^2 + ... + x^k = (1 - x^(k+1))/(1-x), x != 1

    若 |x| < 1，无限和是常数：

    1 + x + x^2 + ... = 1/(1-x) = Theta(1)

    调和和¶

    1 + 1/2 + 1/3 + ... + 1/n = Theta(log n)

    2.6 向下取整和向上取整¶

    对复杂度通常不影响阶：

    floor(n/2) = Theta(n)
ceil(n/2) = Theta(n)

    但写递归式时必须意识到：

    T(n) = T(floor(n/2)) + T(ceil(n/2)) + Theta(n)

    和简化式：

    T(n) = 2T(n/2) + Theta(n)

    通常有相同渐进解。

    3. 递归式与分治¶

    3.1 分治的三步¶

    分治算法把一个大问题拆成相同类型的更小问题：

    1. Divide：把规模为 n 的问题拆成若干子问题；
    2. Conquer：递归解决子问题；
    3. Combine：合并子问题的解。

    一般递归式：

    T(n) = a T(n/b) + f(n)

    其中：

    • a：子问题个数；
    • n/b：每个子问题的规模；
    • f(n)：当前层的拆分和合并成本。

    递归式要写清楚边界：

    T(n) = Theta(1),                     n <= n0
T(n) = a T(n/b) + f(n),              n > n0

    3.2 代入法 Substitution Method¶

    适用场景：你大致知道答案长什么样，需要严格证明。

    三步：

    1. 猜形式：例如猜 T(n) = O(n log n)；
    2. 归纳代入：假设所有更小规模满足猜想，代入递归式；
    3. 处理常数和初始条件：选合适的常数，验证基例。

    例：证明 T(n) = 4T(n/2) + n = O(n^2)¶

    直接假设 T(k) <= c k^2：

    T(n)
<= 4c(n/2)^2 + n
= c n^2 + n

    这里多出了 +n，无法直接推出 <= c n^2。怎么办？

    加强归纳假设，减掉一个低阶项：

    T(k) <= c1 k^2 - c2 k

    则：

    T(n)
<= 4(c1(n/2)^2 - c2(n/2)) + n
= c1 n^2 - 2c2 n + n
= c1 n^2 - c2 n - (c2 n - n)
<= c1 n^2 - c2 n       当 c2 >= 1

    这说明：代入法最容易出错的地方，是只写出“数量级相同”，却没有真正证明归纳假设成立。

    3.3 递归树法 Recursion Tree¶

    步骤：

    1. 画出每层子问题的规模；
    2. 计算每层总成本；
    3. 计算树高；
    4. 对各层求和。

    经典例子：T(n) = 2T(n/2) + cn¶

    每层的总成本都是 cn：

    第 0 层：cn
第 1 层：2 * c(n/2) = cn
第 2 层：4 * c(n/4) = cn
...
叶子层：n * c = cn

    树高为 log_2 n，层数为 log_2 n + 1，因此：

    T(n) = cn(log n + 1) = Theta(n log n)

    3.4 Master Theorem¶

    针对：

    T(n) = aT(n/b) + f(n)

    先计算临界函数：

    n^(log_b a)

    再把 f(n) 和它比较。

    Case 1：递归子问题总成本更大¶

    若存在常数 epsilon > 0：

    f(n) = O(n^(log_b a - epsilon))

    则：

    T(n) = Theta(n^(log_b a))

    例：

    T(n) = 4T(n/2) + n
a = 4, b = 2, n^(log_b a) = n^2
f(n) = n = O(n^(2-1))
=> T(n) = Theta(n^2)

    Case 2：两者同阶¶

    若对某个常数 k >= 0：

    f(n) = Theta(n^(log_b a) log^k n)

    则：

    T(n) = Theta(n^(log_b a) log^(k+1) n)

    例：

    T(n) = 4T(n/2) + n^2
=> T(n) = Theta(n^2 log n)

    Case 3：当前层成本更大¶

    若存在 epsilon > 0：

    f(n) = Omega(n^(log_b a + epsilon))

    并满足正则条件：

    a f(n/b) <= c f(n),  某个常数 c < 1

    则：

    T(n) = Theta(f(n))

    例：

    T(n) = 4T(n/2) + n^3
=> T(n) = Theta(n^3)

    3.5 Master Theorem 不适用的情况¶

    它不是万能公式。比如：

    T(n) = 4T(n/2) + n^2/log n

    这里 f(n) 比 n^2 略小，但不是小一个固定的多项式因子，因此不能直接套标准三种情况。此时用递归树、代入法或更一般的定理。

    3.6 分治的代表：归并排序¶

    思想¶

    1. 把数组分成左右两半；
    2. 递归排序左右两半；
    3. 在线性时间内合并两个有序数组。

    合并的核心¶

    维护两个有序部分的当前最小元素，谁小就把谁放入输出数组。两个数组中的每个元素最多被看一次，所以合并成本是：

    Theta(n)

    伪代码¶

    MERGE-SORT(A, p, r)
    if p < r
        q = floor((p + r) / 2)
        MERGE-SORT(A, p, q)
        MERGE-SORT(A, q + 1, r)
        MERGE(A, p, q, r)

    递归式¶

    T(1) = Theta(1)
T(n) = 2T(n/2) + Theta(n)

    由 Master Theorem Case 2 或递归树：

    T(n) = Theta(n log n)

    特点¶

    • 最好、平均、最坏都是 Theta(n log n)；
    • 稳定，前提是合并时相等元素优先取左边；
    • 经典数组实现需要 Theta(n) 辅助空间；
    • 适合外部排序和需要稳定性的场景。

    4. 排序的基本指标¶

    4.1 稳定性 Stable¶

    若两个记录的排序键相等，排序后它们仍保持原来的相对顺序，则排序稳定。

    例如有记录：

    (2, A), (2, B), (1, C)

    稳定排序后必须是：

    (1, C), (2, A), (2, B)

    而：

    (1, C), (2, B), (2, A)

    就是不稳定。

    稳定性在多关键字排序中很有用：先按次关键字稳定排序，再按主关键字稳定排序，可以得到多关键字结果。

    4.2 原地 In-place¶

    原地排序主要在输入数组内部重排，额外数组空间为 O(1)。递归栈通常单独报告。

    典型情况：

    • 插入、选择、冒泡、堆排序：可以原地；
    • 快速排序：数组分区本身原地，但递归栈仍占空间；
    • 归并排序、计数排序、基数排序：经典实现通常需要额外数组。

    4.3 比较次数和移动次数¶

    排序时间常拆成：

    • 关键字比较次数；
    • 数据移动、交换、复制次数。

    两个算法即使比较次数相近，移动成本也可能明显不同。

    5. 简单排序算法¶

    5.1 插入排序 Insertion Sort¶

    核心思想¶

    维护一个已经有序的前缀，把当前元素插入到前缀中正确的位置。

    可以类比整理扑克牌：手里始终保持有序，每次从桌上拿一张牌，从右向左找位置。

    伪代码¶

    INSERTION-SORT(A)
    for j = 2 to A.length
        key = A[j]
        i = j - 1
        while i > 0 and A[i] > key
            A[i + 1] = A[i]
            i = i - 1
        A[i + 1] = key

    正确性¶

    循环不变量：每次外层循环开始时，A[1..j-1] 已经有序且包含原来的这些元素。当前迭代把 key 插入正确位置后，A[1..j] 有序，因此不变量保持。循环结束时，整个数组有序。

    复杂度¶

    情况 输入特征 时间
    最好 已经升序 Theta(n)
    平均 随机排列 Theta(n^2)
    最坏 逆序 Theta(n^2)
    • 额外空间：O(1)；
    • 稳定：是；
    • 原地：是；
    • 适合：小数组、接近有序的数组、在线逐个插入数据。

    平均情况的理解¶

    插入第 j 个元素时，它在已经排序的前 j-1 个位置中平均落在中间位置，因此平均移动/比较数量是 Theta(j)。总和为：

    sum(j=2..n) Theta(j) = Theta(n^2)

    5.2 选择排序 Selection Sort¶

    核心思想¶

    每轮从未排序后缀中找最小值，与当前位置交换。

    SELECTION-SORT(A)
    for i = 1 to A.length - 1
        k = i
        for j = i + 1 to A.length
            if A[j] < A[k]
                k = j
        if k != i
            swap A[i], A[k]

    复杂度和特点¶

    • 最好、平均、最坏：都是 Theta(n^2)；
    • 额外空间：O(1)；
    • 原地：是；
    • 默认不稳定；
    • 优点：交换次数少，最多 O(n) 次交换。

    如何改成稳定选择排序¶

    不能直接把最小值与 A[i] 交换，因为最小值跨越移动时可能跳过相同键记录。稳定做法是：

    1. 找到未排序区间的最小元素；
    2. 把它取出；
    3. 将它前面的元素整体向右移动一格；
    4. 插入到区间开头。

    这样移动多，但保持了相等元素的相对顺序。

    5.3 冒泡排序 Bubble Sort¶

    核心思想¶

    从后向前扫描，如果相邻元素逆序就交换，让较小元素逐步“冒”到前面。

    BUBBLE-SORT(A)
    for i = 1 to A.length - 1
        noSwap = TRUE
        for j = A.length - 1 downto i
            if A[j + 1] < A[j]
                swap A[j], A[j + 1]
                noSwap = FALSE
        if noSwap
            break

    复杂度和特点¶

    • 最好：Theta(n)，依赖提前终止；
    • 平均、最坏：Theta(n^2)；
    • 额外空间：O(1)；
    • 稳定：是；
    • 原地：是。

    5.4 希尔排序 Shellsort¶

    核心思想¶

    插入排序一次只能移动一格，逆序很远时效率低。希尔排序先选一个较大的间隔 d，对相距 d 的元素做分组插入排序，再逐步减小间隔，最后使用 d=1 的插入排序。

    SHELLSORT(A, gaps)
    for d in gaps from large to small
        perform insertion sort on every d-spaced subsequence

    关键点¶

    • 复杂度强烈依赖间隔序列；
    • 原地：是；
    • 稳定：否；
    • 不能脱离 gap sequence 简单写一个统一复杂度。

    讲义中列举了多种间隔序列。应记住的不是所有公式，而是：

    Shellsort 的性能由 gap sequence 决定。

    某些经典序列可以达到优于 Theta(n^2) 的最坏界，使用形如 2^p 3^q 的序列时，讲义给出 O(n log^2 n) 的复杂度结论。作答时若题目没有指定间隔序列，写“依赖间隔序列”最稳妥。

    6. 高效比较排序¶

    6.1 堆的基本结构¶

    堆是一个可以看成近似完全二叉树的数组对象。

    使用 1 下标时：

    PARENT(i) = floor(i/2)
LEFT(i)   = 2i
RIGHT(i)  = 2i + 1

    最大堆¶

    对每个非根节点：

    A[PARENT(i)] >= A[i]

    因此最大元素在根 A[1]。

    最小堆¶

    对每个非根节点：

    A[PARENT(i)] <= A[i]

    最小元素在根。

    6.2 MAX-HEAPIFY¶

    前提：节点 i 的左右子树已经是最大堆，只有 i 可能违反堆性质。

    MAX-HEAPIFY(A, i)
    l = LEFT(i)
    r = RIGHT(i)
    largest = i
    if l <= heap-size and A[l] > A[largest]
        largest = l
    if r <= heap-size and A[r] > A[largest]
        largest = r
    if largest != i
        swap A[i], A[largest]
        MAX-HEAPIFY(A, largest)

    每次递归只沿一条树高路径向下走，堆高为 O(log n)，所以：

    MAX-HEAPIFY = O(log n)

    6.3 BUILD-MAX-HEAP¶

    叶子节点天然是大小为 1 的堆，只需要从最后一个非叶子节点向前调整：

    BUILD-MAX-HEAP(A)
    heap-size = A.length
    for i = floor(A.length/2) downto 1
        MAX-HEAPIFY(A, i)

    容易误判为 O(n log n)，但精确分析是：

    BUILD-MAX-HEAP = O(n)

    原因：大量节点靠近底部，高度很小；只有少量节点高度较大，所有节点的 height(i) 总和是 O(n)。

    6.4 堆排序 Heapsort¶

    核心思想¶

    1. 建最大堆；
    2. 根部是当前最大值，把它与数组末尾交换；
    3. 缩小堆的有效范围；
    4. 对根做 MAX-HEAPIFY；
    5. 重复。
    HEAPSORT(A)
    BUILD-MAX-HEAP(A)
    for i = A.length downto 2
        swap A[1], A[i]
        heap-size = heap-size - 1
        MAX-HEAPIFY(A, 1)

    复杂度¶

    • 建堆：O(n)；
    • 循环进行 n-1 次，每次调整 O(log n)；
    • 最好、平均、最坏：Theta(n log n)；
    • 原地：是；
    • 稳定：否；
    • 递归版调整的栈空间：O(log n)；迭代版可做到 O(1)。

    优先队列¶

    最大堆还支持：

    操作 作用 复杂度
    MAXIMUM 返回最大元素 O(1)
    EXTRACT-MAX 删除并返回最大元素 O(log n)
    INSERT 插入元素并向上调整 O(log n)
    INCREASE-KEY 增大键并向上调整 O(log n)

    6.5 快速排序 Quicksort¶

    核心思想¶

    1. 选一个 pivot；
    2. PARTITION 把小于等于 pivot 的元素放左边，大于 pivot 的放右边；
    3. 递归排序左右区间。

    PARTITION 的核心不变量¶

    设 pivot 为 x = A[r]，维护下标 i，使得：

    A[p..i]       <= x
A[i+1..j-1]   > x
A[j..r-1]     尚未处理
A[r]          = x

    扫描 j，遇到 A[j] <= x 就增大 i 并交换 A[i] 与 A[j]，最后把 pivot 放到 i+1。

    PARTITION(A, p, r)
    x = A[r]
    i = p - 1
    for j = p to r - 1
        if A[j] <= x
            i = i + 1
            swap A[i], A[j]
    swap A[i + 1], A[r]
    return i + 1

    QUICKSORT(A, p, r)
    if p < r
        q = PARTITION(A, p, r)
        QUICKSORT(A, p, q - 1)
        QUICKSORT(A, q + 1, r)

    复杂度¶

    每次 PARTITION 是 Theta(n)。

    情况 分割形状 时间
    最好 每次平分 Theta(n log n)
    平均/随机 期望较平衡 Theta(n log n) 期望
    最坏 每次一个空区间和一个 n-1 区间 Theta(n^2)

    最坏递归式：

    T(n) = T(n-1) + Theta(n) = Theta(n^2)

    最好递归式：

    T(n) = 2T(n/2) + Theta(n) = Theta(n log n)

    随机化快速排序¶

    随机选择 pivot 可以使任何固定输入上，分割形状具有随机性，期望运行时间为：

    Theta(n log n)

    但它仍然可能以极小概率连续选到极差 pivot，所以随机快速排序的最坏时间仍是：

    Theta(n^2)

    特点¶

    • 通常原地；
    • 不稳定；
    • 缓存表现通常较好；
    • 平均很快；
    • 如果必须保证最坏 O(n log n)，堆排序更稳。

    7. 比较排序的下界¶

    7.1 为什么比较排序不能普遍做到线性¶

    比较排序只能通过比较元素大小来决定结果。它不利用键值的具体数值、位表示或分布。

    典型例子：插入排序、选择排序、冒泡排序、归并排序、堆排序、快速排序，都属于比较排序。

    7.2 决策树模型¶

    把比较排序抽象成一棵二叉决策树：

    • 每个内部节点是一次比较，例如 a_i < a_j；
    • 左右分支对应比较结果；
    • 每个叶子对应一种最终排序结果。

    对于 n 个互异元素，输入可能有 n! 种排列。为了正确排序，每一种排列至少要到达一个可区分的叶子，因此叶子数 l 满足：

    l >= n!

    若树高为 h，二叉树最多有 2^h 个叶子，所以：

    n! <= l <= 2^h

    于是：

    h >= log2(n!) = Omega(n log n)

    因此得到结论：

    任何比较排序算法，在最坏情况下都需要 Omega(n log n) 次比较。

    这也解释了为什么归并排序、堆排序和快速排序的 n log n 是比较模型中的基本极限。

    7.3 线性排序为什么不矛盾¶

    计数排序、基数排序、桶排序能在线性或期望线性时间工作，是因为它们不只比较元素：

    • 计数排序直接利用键值范围；
    • 基数排序利用数字或二进制位；
    • 桶排序利用输入分布假设。

    所以它们没有违反比较排序下界，而是换了计算模型或增加了输入假设。

    8. 线性时间排序¶

    8.1 计数排序 Counting Sort¶

    适用条件¶

    输入是 n 个整数，且每个整数落在较小范围：

    0 <= A[j] <= k

    关键是 k 不能远大于 n。如果 k 极大，初始化和扫描计数数组的成本会很高。

    核心思想¶

    1. C[x] 统计值 x 出现次数；
    2. 前缀和后，C[x] 表示小于等于 x 的元素数量；
    3. 根据 C[A[j]] 把每个元素放到最终位置；
    4. 每放一个相同值，就把对应计数减一。

    伪代码¶

    COUNTING-SORT(A, B, k)
    for i = 0 to k
        C[i] = 0

    for j = 1 to A.length
        C[A[j]] = C[A[j]] + 1

    for i = 1 to k
        C[i] = C[i] + C[i - 1]

    for j = A.length downto 1
        B[C[A[j]]] = A[j]
        C[A[j]] = C[A[j]] - 1

    为什么必须从右向左放¶

    从右向左处理，可以保证相同键的原相对顺序不变，因此计数排序稳定。稳定性是基数排序正确的关键。

    复杂度¶

    时间：Theta(n + k)
空间：Theta(n + k)
稳定：是
经典实现：不是原地

    小例子¶

    A = [2, 5, 3, 0, 2, 3, 0, 3]

    计数后：

    0 出现 2 次
2 出现 2 次
3 出现 3 次
5 出现 1 次

    最终结果：

    [0, 0, 2, 2, 3, 3, 3, 5]

    8.2 基数排序 Radix Sort¶

    核心思想¶

    把每个键看成由 d 个数字组成，从最低位到最高位依次排序：

    最低位 -> 次低位 -> ... -> 最高位

    这是 LSD radix sort。每一位使用稳定排序，通常使用计数排序。

    为什么内层排序必须稳定¶

    当按当前位排序时，较高位已经处理好的相对顺序必须被保留。如果相同当前位的元素顺序被打乱，前面较低位的信息就会丢失。

    复杂度¶

    若每个数字最多有 k 种取值：

    每一位：Theta(n + k)
总共 d 位：Theta(d(n + k))

    若输入是 b 位二进制整数，每一轮处理 r 位，那么：

    d = ceil(b/r)
k = 2^r
T(n) = Theta((b/r)(n + 2^r))

    选择每轮处理多少位¶

    • r 太小：轮数 b/r 太多；
    • r 太大：计数数组 2^r 太大；
    • 常见平衡选择是 r 接近 log n。

    当 b = O(log n) 且 r 接近 log n 时，基数排序可以达到 Theta(n)。

    特点¶

    • 可以稳定；
    • 经典实现需要额外空间；
    • 速度依赖位数、基数和机器表示；
    • 不适用于任意对象，除非能定义可分解的数字键。

    8.3 桶排序 Bucket Sort¶

    适用条件¶

    输入来自 [0, 1) 上的均匀分布。

    核心思想¶

    把 [0,1) 分成 n 个等宽桶：

    B[0], B[1], ..., B[n-1]

    元素 x 放入：

    B[floor(n*x)]

    每个桶内部用插入排序，最后按桶编号依次连接。

    伪代码¶

    BUCKET-SORT(A)
    n = A.length
    let B[0..n-1] be empty lists
    for i = 1 to n
        insert A[i] into B[floor(n * A[i])]
    for i = 0 to n - 1
        sort B[i] with insertion sort
    concatenate B[0], B[1], ..., B[n-1]

    复杂度¶

    设第 i 个桶中有 n_i 个元素，则桶内插入排序成本为：

    sum_i O(n_i^2)

    若输入均匀分布，期望每个桶中的元素数量较小，且：

    E[n_i^2] = 2 - 1/n

    所以期望总时间：

    Theta(n) + n * O(1) = Theta(n)

    结论：

    • 期望时间：Theta(n)，需要均匀分布假设；
    • 最坏时间：Theta(n^2)，所有元素落入同一个桶时；
    • 额外空间：Theta(n)；
    • 若桶内用稳定排序，也可保持稳定性。

    8.4 线性排序怎么选¶

    算法 假设 时间 空间 稳定
    计数排序 整数范围 0..k 较小 Theta(n+k) Theta(n+k) 是
    基数排序 键可分成 d 位/数字 Theta(d(n+k)) 通常额外空间 取决于内层排序
    桶排序 输入近似均匀分布 期望 Theta(n) Theta(n) 取决于桶内排序
    快速排序 无特殊输入假设 期望 Theta(n log n) 原地加栈 否
    堆排序 无特殊输入假设 Theta(n log n) O(1) 或栈 否

    选择算法时不要只看理论阶数，还要看输入是否满足假设。

    9. 顺序统计量与选择问题¶

    9.1 定义¶

    给定 n 个互异数字和整数 i，1 <= i <= n，第 i 个顺序统计量是排序后第 i 小的元素。

    特殊情况：

    • i=1：最小值；
    • i=n：最大值；
    • i=ceil(n/2)：中位数。

    选择问题只要求找到第 i 小元素，不需要把整个数组排序，因此可以突破排序的 Omega(n log n) 下界。

    9.2 最小值和最大值¶

    找最小值至少需要 n-1 次比较，因为除第一个候选外，每个元素都需要至少参与一次比较。

    线性扫描：

    MINIMUM(A)
    min = A[1]
    for i = 2 to A.length
        if A[i] < min
            min = A[i]
    return min

    时间：Theta(n)，比较次数：n-1。

    9.3 同时找最小值和最大值¶

    朴素做法：分别找最小、最大，共 2n-2 次比较。

    更好做法：成对比较。

    1. 先比较一对元素，较小者进入 min 候选，较大者进入 max 候选；
    2. 对每一对，只需要再做一次与当前 min 或 max 的比较；
    3. 每对总共 3 次比较。

    比较次数最多：

    3 floor(n/2)

    当 n 为偶数时还可以写成：

    3n/2 - 2

    9.4 随机化选择 RANDOMIZED-SELECT¶

    核心思想¶

    快速排序会递归处理 pivot 两侧，而选择算法只递归处理包含目标顺序统计量的那一侧。

    RANDOMIZED-SELECT(A, p, r, i)
    if p == r
        return A[p]
    q = RANDOMIZED-PARTITION(A, p, r)
    k = q - p + 1
    if i == k
        return A[q]
    if i < k
        return RANDOMIZED-SELECT(A, p, q - 1, i)
    else
        return RANDOMIZED-SELECT(A, q + 1, r, i - k)

    为什么比快速排序快¶

    快速排序必须解决左右两个子问题：

    T_quick(n) = T(left) + T(right) + Theta(n)

    选择只需要解决一个子问题：

    T_select(n) = T(较大一侧) + Theta(n)

    复杂度¶

    • 最坏：Theta(n^2)，每次 pivot 都极差；
    • 期望：Theta(n)，随机 pivot 使平均递归规模快速下降。

    注意：期望线性不是每次运行都线性，而是对随机选择取平均。

    9.5 最坏线性选择：Median of Medians¶

    目标：不依赖随机性，在最坏情况下也做到 O(n)。

    五分组算法¶

    1. 把 n 个元素分成若干组，每组 5 个，最后可能有不足 5 个的组；
    2. 每组内部找中位数；
    3. 递归找这些组中位数的中位数，记为 x；
    4. 围绕 x 分区；
    5. 根据目标排名 i，只递归进入一侧。

    为什么 pivot 足够好¶

    至少一半的组中，有至少 3 个元素大于等于该组中位数；另至少一半的组中，有至少 3 个元素小于等于该组中位数。

    因此 pivot 两侧都能排除线性数量的元素。标准分析给出：

    最大的递归子问题规模 <= 7n/10 + 6

    于是：

    T(n) <= T(ceil(n/5)) + T(7n/10 + 6) + O(n)

    假设 T(n) <= cn，代入：

    T(n)
<= c(n/5 + 1) + c(7n/10 + 6) + an
= 9cn/10 + 7c + an

    选择足够大的 c 后，右侧不超过 cn，因此：

    T(n) = O(n)

    重要结论¶

    • 排序需要处理全部元素，所以比较模型下有 Omega(n log n) 下界；
    • 选择只需要确定一个排名，不需要完全排序；
    • 因此选择可以在最坏情况下做到 O(n)。

    11. 复杂度分析的做题模板¶

    11.1 循环题¶

    单层循环¶

    for i = 1 to n
    O(1)

    复杂度：Theta(n)。

    嵌套循环¶

    for i = 1 to n
    for j = 1 to n
        O(1)

    复杂度：Theta(n^2)。

    但如果内层上界依赖 i：

    for i = 1 to n
    for j = 1 to i
        O(1)

    应写成求和：

    sum(i=1..n) i = Theta(n^2)

    每次翻倍或减半¶

    i = 1
while i <= n
    i = 2i

    循环次数是 Theta(log n)。

    11.2 递归题¶

    按以下步骤：

    1. 设 T(n) 表示规模为 n 的运行时间；
    2. 写出递归调用数量和规模；
    3. 写出当前层非递归成本；
    4. 写出基例；
    5. 先尝试 Master Theorem；
    6. 不适用时用递归树或代入法。

    11.3 正确性题¶

    按以下顺序：

    1. 写清楚算法维护的性质；
    2. 证明初始化；
    3. 证明一次迭代后性质保持；
    4. 说明终止时性质能推出答案；
    5. 若是递归算法，说明递归子问题正确、合并正确。

    11.4 选择排序算法题¶

    先问四个问题：

    输入值有没有特殊范围或分布？
是否要求稳定？
是否要求原地？
是否必须保证最坏复杂度？

    然后再比较复杂度。不要只看到“线性排序”就直接选，因为计数、基数、桶排序都有输入前提。

    12. 讲义中的应用型复杂度例子：Self-Attention¶

    Topic 1 用自注意力说明算法复杂度不仅是“代码跑几层循环”，还要看中间结果的大小和存储。

    设：

    • 序列长度为 n；
    • 每个 token 的向量维度为 d；
    • X 的形状为 n x d。

    计算：

    Q = X W_Q
K = X W_K
V = X W_V
S = Q K^T / sqrt(d)
A = row-softmax(S)
Y = A V

    其中：

    • Q, K, V 都是 n x d；
    • S 和 A 都是 n x n；
    • 每个 token 都与所有 token 交互。

    复杂度：

    操作 时间 中间存储
    QK^T Theta(n^2 d) n x n
    行 softmax Theta(n^2) n x n
    AV Theta(n^2 d) n x d
    线性投影 Theta(n d^2) n x d

    核心结论：

    固定 d 时，全注意力核心的算术复杂度是 Theta(n^2 d)
注意力矩阵的存储是 Theta(n^2)

    因此序列长度从 n 变为 2n 时，成对交互数量变为 4 倍；从 n 变为 4n 时变为 16 倍。

    如果只允许每个位置看宽度为 w 的窗口，成本降为：

    Theta(n w d)

    当 w 固定时，对 n 近似线性，但代价是失去直接的全局交互。这是“降低复杂度通常伴随建模能力或适用范围变化”的典型例子。

    13. 高频易错点¶

    易错点 1：把 O 当成“等于"¶

    T(n)=O(n^2) 只说明上界，不说明它一定是平方级。能证明紧确阶时写 Theta。

    易错点 2：平均情况不等于把最好和最坏平均¶

    平均情况必须基于明确的输入分布；随机算法的期望情况则通常对随机选择取期望。

    易错点 3：把 Build-Heap 误算成 O(n log n)¶

    逐个插入建堆可能是 O(n log n)，但从底向上执行 BUILD-MAX-HEAP 的标准算法是 O(n)。

    易错点 4：基数排序的内层排序不一定随便¶

    必须使用稳定排序，否则前面已经处理的低位信息会被破坏。

    易错点 5：桶排序的线性时间不是无条件的¶

    它依赖输入近似均匀分布。最坏情况下所有元素进入一个桶，内部插入排序退化到 O(n^2)。

    易错点 6：快速排序平均 n log n 不代表最坏也是¶

    固定 pivot 可能在已排序输入上每次都极不平衡。随机化改善期望，不消除最坏可能。

    易错点 7：选择问题不需要完整排序¶

    找中位数或第 i 小元素时，完整排序通常浪费工作。随机选择期望 O(n)，Median of Medians 最坏 O(n)。

    易错点 8：稳定性不能只看是否交换¶

    选择排序的直接交换会跨越相等元素，因此通常不稳定；通过移动而非交换可以改成稳定版本。

    易错点 9：Master Theorem 不是所有递归式都能套¶

    必须先检查是否是 aT(n/b)+f(n) 的标准形式，以及 f(n) 是否满足某一条增长关系和必要条件。

    易错点 10：只写结论不写理由¶

    考试中复杂度结论通常要能追溯到：循环次数、每层成本、递归树高度、比较次数或输入假设。

    14. 最后背诵清单¶

    必背定义¶

    • O：上界；
    • Omega：下界；
    • Theta：紧确界；
    • 稳定排序；
    • 原地排序；
    • 最坏、平均、期望复杂度；
    • 顺序统计量。

    必背复杂度¶

    Insertion Sort: best Theta(n), worst Theta(n^2)
Selection Sort: Theta(n^2)
Bubble Sort: best Theta(n), worst Theta(n^2)
Merge Sort: Theta(n log n)
Build-Max-Heap: O(n)
Heapify: O(log n)
Heapsort: Theta(n log n)
Quicksort: expected Theta(n log n), worst Theta(n^2)
Counting Sort: Theta(n+k)
Radix Sort: Theta(d(n+k))
Bucket Sort: expected Theta(n), worst Theta(n^2)
Randomized-Select: expected Theta(n), worst Theta(n^2)
Median-of-Medians Select: worst O(n)

    必背公式¶

    1 + 2 + ... + n = Theta(n^2)
1 + 1/2 + ... + 1/n = Theta(log n)
T(n) = 2T(n/2) + Theta(n) = Theta(n log n)

    必背证明套路¶

    循环算法：循环不变量 = 初始化 + 保持 + 终止
递归算法：基例 + 递归子问题正确 + 合并正确
复杂度：写 T(n) + 处理基例 + 解递归式
比较排序下界：n! 个排列 + 二叉决策树 + n! <= 2^h
随机选择：每次只递归一侧，期望总成本线性
最坏线性选择：五分组 + 中位数的中位数 + 丢掉常数比例元素

    一句话理解整门课¶

    先证明算法真的解决了问题，再用渐进分析判断它是否能扩展到大规模输入；当比较模型遇到下界时，就利用输入的数值范围、位结构、分布或“只求部分顺序”的特性换取更快算法。
