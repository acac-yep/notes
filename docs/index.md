## 怎么用这套东西

1. **查考点**：搜索框直接搜关键词（如「变分」「DPO」），比翻 PDF 快。
2. **读论文**：先看每篇的「0. 三十秒速览」判断相关性，再决定读不读正文。
3. **做实验**：每篇笔记最后一节是「可复现要点」，按编号做即可。
