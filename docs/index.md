## 怎么翻

找东西直接搜，中文分词已经开好了，比翻 PDF 快。

读论文先扫一眼每篇开头的「三十秒速览」，觉得跟我相关再往下看；真要动手复现，跳到「可复现要点」，按编号一条条来。
