# 关于

我是王子涵，中科大计算机学院大三。

平时看推荐系统多一些，最近主要盯着生成式推荐这一路。另外一直在想 LLM agent 在工业推荐的迭代里能顶多少事——从这几篇工业界的报告看，写代码、跑实验、做归因已经能接，提方向还是得靠人。

这个站是给自己用的。考试前翻速通页，组会前翻论文笔记，平时想到什么就顺手记两笔。内容都是自己过了一遍才写的，不是把摘要抄过来；有些东西网上的说法互相打架，自己写一遍才知道哪儿没想明白。

## 站是怎么搭的

Material for MkDocs + GitHub Pages，`mkdocs gh-deploy` 一条命令发出去。公式走 MathJax，流程图用 Mermaid，中文搜索靠 jieba 分词。

笔记的写法参考了 [DeepPaperNote](https://github.com/917Dhj/DeepPaperNote) 的 evidence-first：每个数字都要能回到原文的章节或表格，作者没证明的事单独拿出来说。以前写笔记最容易犯的毛病是「我记得好像涨了 5%」，回头查不着，等于白写。
