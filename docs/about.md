## 这个站怎么搭的

| 部分 | 用了什么 |
|---|---|
| 站点生成 | [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) |
| 托管 | GitHub Pages（`mkdocs gh-deploy` 一条命令） |
| 公式 | MathJax（`$...$` / `$$...$$`） |
| 流程图 | Mermaid |
| 搜索 | Material 内置，中文用 jieba 分词 |

笔记内容来自我自己的阅读与整理；写笔记的方法参考了 [DeepPaperNote](https://github.com/917Dhj/DeepPaperNote) 的 evidence-first 思路：每个数字都要能回到原文的章节或表格。
