## 核心考点

### 三类属性

- 标识符（Identifier）：直接识别个人，如姓名、身份证号、手机号。
- 准标识符（QI）：单个不识别，但可与外部数据连接后重新识别。经典组合是 {年龄, 性别, 邮编}。
- 敏感属性：社会属性、健康状况、收入等，需要被保护但不能泛化掉。

### k-匿名

- 等价类：在 QI 属性组上取值完全相同的记录集合。
- k-匿名：表 $T$ 上每个等价类的大小至少为 $k$。
- 目标：任何一条记录至少和另外 $k-1$ 条记录不可区分。
- 实现手段：泛化（generalization，值变成区间/祖先节点）+ 抑制（suppression，删行或置空）。

### Mondrian

- 思想：把 QI 看成多维空间中的点，递归地在某一维的中位数处切分，直到每个分区记录数 < 2k（不能再合法切）。
- 合法切分条件（$k$-维）：在维度 $j$ 上以 $v$ 切分，要求两侧记录数都 ≥ $k$：

$$
\big|\{t : t.x_j > v\}\big| \ge k \quad\text{且}\quad \big|\{t : t.x_j \le v\}\big| \ge k
$$

- 维度选择（传统）：$j^*=\arg\max_j \mathrm{normWidth}_j$，即归一化跨度最大的维度，尽量把点摊开。
- 严格划分：中位数落在切分点上的记录直接归入一侧；松弛划分：把「$t.j = v$」的记录平均分到左右子集（分区为奇数时左多一条）。
- 类别属性不能取范围，需要预定义泛化层次树：把值逐级换成共同祖先。

### 效用度量

数值属性的 NCP（归一化确定性惩罚）：

$$
\mathrm{NCP}_A(t)=\frac{d-a}{|A|},\qquad |A|=\max_{t'\in T} t'.A-\min_{t'\in T} t'.A
$$

类别属性的 NCP：

$$
\mathrm{NCP}_A(t)=\frac{|\mathrm{leaves}(\mathrm{LCA}(t))|}{|A|}
$$

其中分子是泛化后公共祖先子树的叶子数，分母是整棵泛化树的叶子总数（全部可能取值数）。

GCP（全局确定性惩罚）：

$$
\mathrm{GCP}(T)=\frac{\sum_{t\in T}\sum_{j=1}^{n}\mathrm{NCP}_{A_j}(t)}{|T|\cdot n}
$$

- GCP = 0：完全没泛化，信息零损失（但也等于没匿名）。
- GCP = 1：整表塌成一个等价类，泛化到最顶层。

### Workload-aware

- 传统：只看归一化跨度，忽略下游任务关心哪个维度。
- 加权：$\mathrm{score}_j = w_j \times \mathrm{normWidth}_j$，$j^*=\arg\max_j \mathrm{score}_j$，只在不违反合法切分条件的维度里比。
- 效果：重要维度被切得更细、泛化损失小；但总 GCP 可能变差——这正是实验要讨论的 trade-off。

## 高频题型

1. **给一张表判断是否 k-匿名**
   先确定 QI 列 → 按 QI 分组 → 数每个等价类大小 → 与 k 比较。
2. **手算 NCP / GCP**
   数值列先算全局极差，再算每条记录被泛化区间的宽度；类别列数泛化树叶子。最后按记录数与属性数平均。
3. **严格 vs 松弛划分**
   给一组数和中位数，写出两种划分结果；说明松弛划分左右记录数相等（奇数时左多 1）。
4. **为什么 workload-aware 可能降低 GCP 但提升分类效用**
   把权重给下游任务关心的列 → 该列保留更多细节 → 分类特征更细；代价是别的列被粗化，总 GCP 上升。
5. **k 增大时 GCP 与运行时间怎么变**
   GCP 单调上升（等价类更大、泛化更粗）；运行时间随切分次数增加，但数据量小时不明显。

## 易错点

- 混淆标识符与准标识符：邮编单独不识别个人，属 QI；姓名是标识符。
- 以为 k-匿名能防住所有攻击：它只保证「无法从 QI 唯一定位」，对同质攻击（等价类内敏感值全相同）无效。
- 类别属性写「取范围」，例如 `Male~Female`——课件明确说类别型的范围没有意义，必须走泛化树。
- GCP 公式漏掉除以属性数 $n$，或漏掉除以记录数。
- 松弛划分里把中位数记录全给左边（那是严格划分）。
- 只比较不合法划分的维度，导致切完后某侧记录数 < k。

## 一页速记

- 三类属性：标识符、QI、敏感属性。
- k-匿名 = 每个等价类 ≥ k 条。
- Mondrian：按中位数切、按归一化跨度选维、只做合法切分。
- 严格：中位点归一侧；松弛：中位点两侧平分。
- 类别属性用泛化树，不用范围。
- NCP 数值 = 区间宽 / 全局极差；类别 = 祖先叶子数 / 总叶子数。
- GCP = 所有记录所有属性 NCP 的平均，0 无损、1 全泛化。
- workload-aware：score = 权重 × 归一化跨度。
- k ↑ → GCP ↑、匿名性 ↑。
- k-匿名不防同质攻击与背景知识攻击。
