## 0. 这门课在讲什么

从零实现一个语言模型的全流程：分词 → 模型结构 → 训练 → 数据 → 对齐 → 推理 → 评测 → scaling。重点是「自己写一遍」，而不是调库。

## 1. 考点地图

| 模块 | 必须能手写/推导 | 常见考法 |
|---|---|---|
| Tokenizer | BPE 训练与编码 | 给定语料做合并、算压缩率 |
| Transformer | 多头注意力、RoPE、RMSNorm、残差 | 写 forward、算参数量与 FLOPs |
| 训练 | AdamW、学习率调度、混合精度 | 手推更新式、解释 warmup |
| 数据 | 去重、过滤、配比 | 设计一个去重流程 |
| 对齐 | SFT、RLHF/DPO 损失 | 推导 DPO 目标 |
| 推理 | KV cache、采样策略 | 算 cache 显存、top-p 实现 |
| 评测 | perplexity、下游任务 | 解释 PPL 与 loss 的关系 |

## 2. 核心公式

交叉熵与困惑度：

$$
\mathcal{L}=-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(x_i\mid x_{<i}),
\qquad
\mathrm{PPL}=\exp(\mathcal{L})
$$

注意力：

$$
\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$
