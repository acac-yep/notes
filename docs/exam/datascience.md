## 核心考点

### 1.1 数据科学基础

- 数据定义（计算机科学口径）：所有能输入计算机并被程序处理的符号的总称。
- 大数据 4V：Volume 数据量大、Variety 类型多、Velocity 高实时性、Value 价值巨大但价值密度低。
- Value 的比喻是沙里淘金：从海量数据中挖稀疏但珍贵的信息，价值密度低与潜在价值高并存。
- 1 秒定律：大数据应用须在 1 秒内形成答案，否则结果过时、无意义；典型场景为实时欺诈检测、自动驾驶、金融监控、入侵检测。
- 量级链：KB → MB → GB → TB → PB → EB → ZB → YB → NB → DB；PB 是大数据层次的临界点。
- PB 以上级别数据，最有效传输方式是空运而非网络。
- 三种数据形态：结构化（关系数据库）、半结构化（XML/JSON 文档）、非结构化（音视频、图像、文本）。
- 三种处理形态：批处理 Batch、流式处理 Streams、实时处理 Real Time。
- 以模型为中心：围绕任务特性设计网络结构，代表为 GNN、RNN、CNN、Transformer。
- 以数据为中心：增加数据数量、改善数据质量，手段为数据蒸馏、数据选择、数据生成。
- 数据规模样例：CIFAR-10 6 万张、ImageNet 1400 万张、LAION-5B 58.5 亿图像-文本对（约 80TB）。
- GPT 线数据：GPT 5GB 文本/1.17 亿参数；GPT-2 40GB/15 亿（zero-shot）；GPT-3 45TB/1750 亿（few-shot）；GPT-4 1PB 多模态/1.76 万亿参数。
- 全球数据量：2024 年 149ZB，2028 年预计 394ZB 以上。
- 概念起点：2008 年 9 月《Nature》首出大数据专刊，提出"大数据真正重要的是新用途和新见解，而非数据本身"。
- 我国战略节点：2015 年十八届五中全会首提"国家大数据战略"；2020 年大数据列为新型生产要素；2021 年《"十四五"大数据产业发展规划》定四大任务；2024 年《"数据要素×"三年行动计划》。
- 规模数字：2024 年数字经济 59.2 万亿元、占 GDP 43.8%；2025 年数据生产总量 52.26ZB、占全球 27.44%。
- 数学支撑四例：优化（梯度下降、牛顿方向、收敛性）、聚类（特征值分解、奇异值分解、QR 分解）、图卷积（图上的傅里叶变换与卷积）、概率统计。
- 应用面：智慧教育、智慧医疗、智慧城市、智慧司法、安防舆情、电商计算广告、文化娱乐、企业管理。
- 智慧教育链路：图文识别 → 公式转写 → 试题切分 → 属性标注 → 难度预估 → 自动组卷 → 变形题生成 → 相似题检索。

### 1.2 科研范式与人工智能

- 四范式由 Jim Gray 于 2007 年总结，按"方法—载体—时间"三列记忆。
- 第一范式经验科学：以归纳法为主，带盲目性的观测与实验，载体是科学实验。
- 第二范式理论科学：以演绎法为主，关注理论总结与理性概括，载体是数学模型。
- 第三范式计算科学：重视数据模型构建与定量分析，用计算机分析求解，载体是科学计算。
- 第四范式数据密集型科学：先有大量已知数据，再由计算得出此前未知的理论，载体是机器学习。
- 第五范式 AI4R（李国杰，2024）：科研全过程智能化、人机融合、依托大模型与大平台、面向复杂系统非确定性问题，载体如机器化学家。
- 智能三级演进：计算智能（规则明确、特定领域，如棋类）→ 感知智能（语音、图像、视频）→ 认知智能（理解、推理、解释）。
- 两种建模范式：一任一模为每任务维护一个模型、参数难共享迁移、稀疏标签场景差；千任一模共享基础大模型参数、具备任务泛化、缓解稀疏样本窘境。
- ABC 技术体系：AI（算法 Algorithm）+ Big data（数据）+ Computation（算力）；数据是人工智能发展的基石。
- 现阶段人工智能的核心：对大数据做特征抽取 + 机器学习算法；流程为带标签数据训练 → 模型 → 新数据 → 分类/预测。
- 决策树示例：以 Marital Status、Annual Income、Home Owner 逐层划分，叶结点给出 Defaulted Borrower 的 Yes/No。
- 三层关系：逻辑关系（归纳法、数理逻辑、布尔代数）、相关关系（贝叶斯网络、机器学习、深度学习）、因果关系（有方向、存在时序先后性）。
- AGI 五级：L1 基础对话者、L2 推理者、L3 智能行动者、L4 创新者、L5 组织者（L5 即真正 AGI）。
- 强化学习里程碑：2016 年 AlphaGo 4:1 击败李世石；2020 年 AlphaFold 蛋白质折叠平均准确率超 90%；2022 年 ChatGPT 用 RLHF 微调；2025 年 DeepSeek 提出 GRPO。
- 机器化学家：智能阅读 16000 篇论文自主遴选 5 种非贵金属元素，融合 2 万组理论计算数据与 207 组实验数据，指导贝叶斯优化从 55 万种金属配比中找出最优高熵催化剂。
- 思维链 CoT：向模型展示少量带推理过程的样本，模型回答时先输出推理过程再给结论。
- 学时与考核：基础 2 周、数据分析 4 周、数据统计 3 周、数据挖掘与机器学习 4 周、前沿专题 4 周、汇报回顾 1 周；课堂 30% + 调研 30% + 实验 40%。

### 2.1 数据分析：数据采集

- 三条获取路径：数据检索与开源、批量数据获取（爬虫或购买）、数据生成。
- 网络爬虫定义：按一定规则自动抓取万维网信息的程序或脚本，即请求网站并提取数据的自动化程序。
- 爬虫三步：载入 → 解析 → 存储；其中最复杂的部分是载入。
- 载入动作：向服务器发 Request，收 Response（响应头 + 响应体即网页源码，状态码如 200、404）。
- GET：参数常放在 URL 中，问号后即参数，如 `http://www.abc.com?p=1&q=2&r=3`。
- POST：参数放在表单/请求体中，比 GET 多 Form Data 部分，更安全，登录操作常用。
- 动态加载页（Ajax）：部分数据需浏览器用 JavaScript 调接口渲染，需点击下拉等操作才触发。
- Ajax 两条解法：抓包分析该次操作的请求并用代码复现（有难度但抓取快）；用 selenium webdriver 驱动浏览器模拟人工操作（简单但慢，因需渲染页面）；其他工具如 Splash、PyV8。
- 反爬手段：出现登录界面与验证码、封禁固定账号或 IP 一段时间、直接返回错误的无用数据。
- 反爬对策：优化程序减少访问次数、避免抓取重复内容、使用多个 cookie、使用多个 IP（代理实现）。
- 常用工具：Java 侧 HttpClient、Jsoup；Python 侧 Scrapy、BeautifulSoup，推荐 Scrapy（能控流程、处理异常）。
- 解析对象对比：XML 是标签树（可嵌套 province/cities/city）；JSON 是对象与键值对，城市为数组。
- 合规红线：注意网站规定与法律规定，2021 年 6 月 1 日《中华人民共和国数据安全法》施行，注意数据使用规范。
- 公开数据集：ImageNet、MovieLens 用户评分、SNAP 大规模网络、ASSISTments 与 EduData 教育数据、阿里天池、KDDCup/NeurIPS 竞赛数据；Google Dataset Search 支持中文检索。
- 数据合成三例：Self-Instruct 以少量种子任务驱动大模型生成新指令并过滤迭代扩充；ControlNet 注入边缘图、人体骨骼姿态定向合成受几何约束的图像；视频生成已涌现一定物理仿真能力。
- AIGC 覆盖：文本、图像、音频、视频、代码、跨模态生成，可定制化产出所需数据。
- 以数据为中心的 AI：GPT 进化中模型结构保持相似，数据规模与质量大幅提升；模型对数据的需求急速上升。
- DeepSeek-V4 的四招：专家分立（数学/代码/智能体独立训练）、动态生成（代码沙箱自主探索合成数万步轨迹）、真值验证（真实编译器与求解器闭环过滤幻觉）、在线蒸馏（Reverse-KL 散度聚合多专家）。
- FAIR 原则：可发现 Findable、可访问 Accessible、可互操作 Interoperable、可复用 Reusable。
- FAIR-R 是面向 AI 的扩展：增加"AI 就绪"，审计数据偏见、强化机器可读性与版权合法性。
- AI-Ready 数据集指经格式统一、清洗除错、精准标注后即取即用的数据，代表：WeatherBench 气象、MIMIC 医学、nuScenes 智驾、Materials Project 材料、Galaxy Zoo 天文、LOBSTER 金融。
- 四个数据集的重构要点：MIMIC 把异构监护数据对齐成关系数据库；WeatherBench 重构成规则三维网格并用 Zarr 存储；Materials Project 统一 CIF 格式并用 DFT 算出能带间隙、形成能作真值；nuScenes 做毫秒级时间同步与空间标定，人工标 3D 边界框与唯一追踪 ID。

## 公式与数字

- 线性回归损失与最优参数：目标是找到合适的 $w$ 使 $f(w,x)$ 最接近 $D$。

$$L(w)=\sum_{d_i\in D} f(w,x_i)-y_i,\qquad w=\arg\min_{w} L(w)$$

- 优化问题的一般形式与解法：

$$\min_{x\in\mathbb{R}^{n}} f(x)$$

求解手段为梯度下降、牛顿法/拟牛顿法，沿负梯度方向或牛顿方向搜索。

- PageRank（Larry Page、Sergey Brin，1998，斯坦福，Google 早期排序核心）：

$$PR(A)=\frac{1-d}{N}+d\times\sum_{T_i}\frac{PR(T_i)}{C(T_i)}$$

其中 $d$ 为阻尼系数，通常取 0.85；$T_i$ 为指向 A 的页面；$C(T_i)$ 为页面 $T_i$ 的出链数；$N$ 为页面总数。

- Scaling law 单因素幂律拟合（Kaplan 等，2020）：

$$L=(C_{\min}/2.3\times 10^{8})^{-0.050}$$

$$L=(D/5.4\times 10^{13})^{-0.095}$$

$$L=(N/8.8\times 10^{13})^{-0.076}$$

- Scaling law 合并形式（$N$ 参数量、$D$ 数据量、不可约损失 $E$）：

$$L(N,D)=E+\frac{A}{N^{\alpha}}+\frac{B}{D^{\beta}}$$

三要素必须同步放大，否则性能被最短板卡住。

- 容量换算（课件按 $2^{10}$ 递进）：

$$1\,\text{ZB}=2^{10}\,\text{EB}=2^{20}\,\text{PB}=2^{30}\,\text{TB}=2^{40}\,\text{GB}$$

参照物：1 ZB 约等于地球沙粒总量，1 EB 约等于 4000 个美国国会图书馆藏书；TB 记 $2^{30}$ KB、PB 记 $2^{40}$ KB、ZB 记 $2^{60}$ KB。

- 规模数字：LAION-5B 58.5 亿对/80TB；ImageNet 1400 万张；CIFAR-10 6 万张；GPT-3 45TB 文本/1750 亿参数；GPT-4 1PB 多模态/1.76 万亿参数；ChatGPT 语料 96% 以上为英文，其余 20 个语种合计不足 4%。
- 成绩构成：课堂 $30\%$ + 调研 $30\%$ + 实验 $40\%$。

## 高频题型

1. 简述大数据 4V 并各举一例：先给 4 个英文词与中文释义，每条配一个课件例子（如 Variety 配音视频与 JSON），Value 必须补"密度低"。
2. 数据量换算题：给 GB 数逐级除以 $2^{10}$ 换算到 TB/PB/ZB，判断是否越过 PB 临界点，再问迁移方式（答案：物理空运）。
3. 数据形态归类题：给 MySQL 表、JSON 接口返回、监控视频、XML 配置，按结构化/半结构化/非结构化三分类，并说明处理形态（Batch/Streams/Real Time）。
4. 爬虫设计题模板：定入口 URL → 抓包确定 GET/POST 与参数位置 → 发请求校验状态码 200/404 → 解析（JSON 取键值、XML 走标签树）→ 落库存储 → 加反爬对策（降频、去重、cookie 池、IP 代理）。
5. 四范式辨析题：用"范式—方法—载体—例子"四列作答（归纳/实验、演绎/数学模型、定量计算/科学计算、先数据后理论/机器学习），再补第五范式的"全过程智能化 + 人机融合 + 大模型大平台"。
6. 模型中心与数据中心对比题：从关注对象（结构 vs 数量与质量）、代表工作（GNN/Transformer vs 数据蒸馏/选择/生成）、证据（GPT 结构相似而数据规模质量跃升）三点作答。
7. Scaling law 读图题：对数坐标下直线斜率即幂指数，说明损失随参数量、数据量、计算量幂律下降，并指出三要素需同步放大。
8. 决策树推演题：按 Marital Status → Annual Income → Home Owner 顺序逐层判断，落到叶结点读出 Defaulted 的 Yes/No。

## 易错点

- 只答 Volume 与 Variety，漏掉 Velocity 与 Value；Value 写成"价值高"而丢掉"价值密度低"这一半。
- 按 $10^3$ 换算容量（1 ZB = 1000 EB），与课件的 $2^{10}$ 递进冲突，数值差约 7%。
- 把 JSON/XML 当结构化数据；课件口径是关系数据库为结构化，XML/JSON 文档为半结构化。
- GET 与 POST 的参数位置写反，或说 POST"参数在 URL 问号后"；课件明确 POST 参数在请求体/表单，登录用它是因为更安全。
- 反爬对策写成"提高并发、加快访问"，方向相反；课件对策是降频、去重、换 cookie 与 IP。
- 认为 selenium 比抓包复现更快；selenium 要启动浏览器渲染页面，属于简单但慢的方案。
- 第四范式说成"先有理论再找数据验证"；课件定义是先有大量已知数据、再由计算得出未知理论。
- 第五范式简化成"用大模型做实验"；课件强调科研全过程智能化、人机融合、复杂系统非确定性问题。
- 用后续章节的准确率、F1、余弦相似度回答这三份课件；三段内容不含距离、相似度与评估指标公式，硬套即错。

## 一页速记

1. 数据 = 所有能输入计算机并被程序处理的符号的总称。
2. 4V：Volume 量大、Variety 类型多、Velocity 高实时、Value 价值大而密度低。
3. 1 秒定律：1 秒内出不了答案，结果即过时。
4. 量级链 KB→MB→GB→TB→PB→EB→ZB→YB→NB→DB，PB 为大数据临界点。
5. 换算按 $2^{10}$ 递进，$1\,\text{ZB}=2^{40}\,\text{GB}$；PB 以上靠空运迁移。
6. 结构化=关系库，半结构化=XML/JSON，非结构化=音视频图像文本。
7. 模型中心拼结构（GNN/RNN/CNN/Transformer），数据中心拼数量与质量（蒸馏/选择/生成）。
8. 四范式：归纳实验、演绎理论、定量计算、先数据后理论；第五范式 AI4R 是全过程智能化。
9. 一任一模 → 千任一模：共享基础大模型参数，任务泛化，缓解稀疏样本。
10. ABC：算法 + 大数据 + 算力，数据是人工智能的基石。
11. 爬虫三步：载入（GET 在 URL，POST 在请求体）→ 解析（XML 标签树/JSON 键值）→ 存储。
12. 反爬四招：降频、去重、多 cookie、多 IP 代理。
13. Scaling law：损失随参数、数据、算力幂律下降，三者须同步放大。
14. FAIR 四性：可发现、可访问、可互操作、可复用；FAIR-R 再加"AI 就绪"。
15. AI-Ready 代表集：MIMIC 医学、WeatherBench 气象、nuScenes 智驾、Materials Project 材料。
