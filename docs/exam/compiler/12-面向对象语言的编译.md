# 第 12 章 面向对象语言的编译

## 学习定位

本章在教材中属于扩展章节，但如果课程实践涉及 Java/C++/面向对象语义，就很有用。重点理解对象、类、继承、封装、动态派发如何影响类型检查、运行时布局和代码生成。

## 对象和类

类描述对象的字段和方法。对象是类的实例，运行时通常包含：

- 字段数据。
- 指向类信息或虚函数表的指针。
- 运行时类型信息。

字段访问可以看作基地址加偏移：

```text
x.f = *(base(x) + offset(f))
```

## 继承

继承让子类复用父类字段和方法。编译器需要安排对象布局，使父类字段在子类对象中也能按一致方式访问。

单继承较简单：子类对象通常以前缀形式包含父类部分。

多重继承更复杂：对象可能含多个父类子对象，方法调用时可能需要调整 `this` 指针。

## 信息封装

访问控制如 `private/protected/public` 多数在编译期检查。运行时代码通常不再反复检查普通访问权限。

封装影响语义分析：编译器要知道当前访问位置是否允许访问某字段或方法。

## 方法调用

方法调用分为静态绑定和动态绑定。

静态绑定：编译期确定调用哪个函数。

动态绑定：运行期根据对象真实类型决定调用哪个方法。实现常用虚函数表。

虚函数表思想：

```text
对象 -> vtable 指针 -> 方法入口地址数组
```

调用 `obj.m()` 时：

```text
t1 = obj.vptr
t2 = t1[offset(m)]
call t2
```

## 类型检查

面向对象语言常有子类型规则。若 `Dog` 是 `Animal` 的子类，则 `Dog` 对象可在需要 `Animal` 的地方使用。

赋值规则可写成：

```text
E.type <: T
----------------
T x = E 合法
```

其中 `<:` 表示子类型关系。

## 继承的编译方案

单一继承中，父类字段偏移保持不变，子类新增字段追加在后面。方法表中，重写方法覆盖父类槽位，新增方法追加槽位。

这样父类引用指向子类对象时，仍能按父类布局访问字段和调用方法。

## 典型题型

1. 说明对象运行时布局。
2. 解释动态绑定和虚函数表。
3. 判断子类型赋值是否合法。
4. 说明继承如何影响字段偏移和方法表。

## 易错点

- 重载和重写不同：重载看参数签名，重写看继承关系中的同签名方法替换。
- 动态派发针对方法调用，不是所有字段访问都动态查找。
- 子类对象能当父类用，不代表父类对象能当子类用。
- 多重继承可能需要 `this` 指针调整。
