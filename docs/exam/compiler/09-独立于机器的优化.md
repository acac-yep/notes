# 第 9 章 独立于机器的优化

## 学完要会什么

你要能识别常见优化机会，理解数据流分析的基本框架，能写到达定值、活跃变量等数据流方程，并能说明循环优化为什么重要。

## 优化的原则

优化必须保持程序语义。优化目标可能是：

- 减少执行时间。
- 减少代码大小。
- 减少访存。
- 减少能耗。

本章“独立于机器”指优化主要发生在中间代码层，不依赖具体指令集。

## 常见局部优化

基本块内可做：

- 公共子表达式删除。
- 复制传播。
- 常量折叠。
- 常量传播。
- 死代码删除。
- 强度削弱。

例子：

```text
t1 = a + b
t2 = a + b
x = t2
```

若 `a`、`b` 中间未改变，则 `t2` 可替换为 `t1`。

复制传播：

```text
x = y
z = x + 1
```

可改为：

```text
z = y + 1
```

若 `x` 后续不再使用，`x = y` 可进一步删除。

## DAG 优化

基本块可构造成 DAG：叶子是变量或常量，内部节点是运算。相同运算和相同操作数组合可共享节点，用于发现公共子表达式。

DAG 还能帮助删除无用赋值：如果某节点结果不会影响基本块出口活跃变量，就可以删除。

## 数据流分析框架

数据流分析在流图上求解信息集合。

通用形式：

```text
OUT[B] = f_B(IN[B])
IN[B]  = 合并所有前驱的 OUT
```

或反向问题：

```text
IN[B]  = f_B(OUT[B])
OUT[B] = 合并所有后继的 IN
```

关键要素：

- 方向：正向或反向。
- 合并运算：并集或交集。
- 传递函数：通常由 `gen` 和 `kill` 表示。
- 初值和迭代顺序。

## 到达定值

一个定值 `d: x = ...` 到达某点，表示存在一条路径从 `d` 到该点，且路径上没有重新给 `x` 定值。

它是正向、may 问题，合并用并集。

方程：

```text
IN[B]  = union OUT[P]，P 是 B 的前驱
OUT[B] = gen[B] union (IN[B] - kill[B])
```

应用：常量传播、复制传播、未初始化检查。

## 活跃变量

变量在某点活跃，表示从该点出发存在路径会使用它当前值，且在使用前没有重新定值。

它是反向、may 问题，合并用并集。

方程：

```text
OUT[B] = union IN[S]，S 是 B 的后继
IN[B]  = use[B] union (OUT[B] - def[B])
```

应用：死代码删除、寄存器分配。

## 可用表达式

表达式在某点可用，表示从入口到该点的每条路径都已计算过该表达式，并且操作数没有被改写。

它是正向、must 问题，合并用交集。

应用：公共子表达式删除。

## 循环优化

循环执行次数多，是优化重点。

常见循环优化：

- 循环不变代码外提。
- 归纳变量识别。
- 强度削弱，如乘法变加法。
- 删除冗余归纳变量。

自然循环通常由回边形成。识别循环前要先理解支配关系：若所有从入口到 `n` 的路径都经过 `d`，则 `d` 支配 `n`。

## 典型题型

1. 对基本块做 DAG 优化。
2. 找公共子表达式、复制传播、死代码。
3. 给流图写到达定值方程并迭代求解。
4. 给流图写活跃变量方程。
5. 识别循环不变代码和归纳变量。

## 易错点

- may 问题通常用并集，must 问题通常用交集。
- 到达定值是正向，活跃变量是反向。
- 死代码删除不能删除有副作用的语句，例如函数调用、I/O、可能抛异常的操作。
- 公共子表达式成立的前提是操作数中间未被改变。
