# 第 8 章 代码生成

## 学完要会什么

你要能理解目标代码生成器的输入输出，能划分基本块、构造流图，能用简单算法从三地址码生成目标代码，并理解寄存器分配的核心矛盾。

## 代码生成器面对的问题

目标代码生成不仅是“翻译指令”，还要处理：

- 指令选择：用哪些目标机指令实现中间操作。
- 寄存器分配：哪些值放寄存器，哪些值放内存。
- 计算次序：先算哪个子表达式更省寄存器。
- 地址计算：变量、数组、临时变量的地址。
- 调用约定：参数、返回值、保存寄存器。

## 目标语言和指令代价

简单目标机可抽象为：

```text
LD  R, x      R = x
ST  x, R      x = R
ADD R, x      R = R + x
SUB R, x
MUL R, x
```

指令代价可用指令数、访存次数、周期数估计。真实机器上访存通常比寄存器操作贵。

## 基本块

基本块是一段顺序执行的代码，只有入口第一条和出口最后一条。

划分方法：

1. 第一条语句是入口。
2. 任意跳转目标是入口。
3. 任意跳转语句的下一条是入口。
4. 每个入口到下一个入口之前构成一个基本块。

## 流图

流图节点是基本块，边表示控制流可能从一个基本块转到另一个基本块。

若基本块 `B1` 末尾是 `goto B2`，则有边 `B1 -> B2`。若条件跳转失败后继续执行下一块，也有一条落空边。

流图是后续数据流分析和优化的基础。

## 下次引用信息

生成局部代码时，要知道变量之后是否还会被用到，以及下一次使用在哪里。

如果某个变量当前值已经在寄存器中，且之后不再使用，就可以覆盖该寄存器。若变量之后还要用，覆盖前要确保它的值已保存。

## 简单代码生成算法

对三地址语句：

```text
x = y op z
```

基本思路：

1. 为 `y` 选择一个寄存器，必要时从内存装入。
2. 对该寄存器执行 `op z`。
3. 让寄存器保存 `x` 的值。
4. 更新地址描述符和寄存器描述符。

地址描述符记录某变量当前值在哪些位置；寄存器描述符记录某寄存器当前装了哪些变量。

## 寄存器分配

寄存器是稀缺资源。寄存器分配要决定哪些值常驻寄存器，哪些值溢出到内存。

常见思想：

- 局部寄存器分配：在基本块内部用下次引用信息。
- 全局寄存器分配：跨基本块考虑活跃范围，常用图着色思想。

如果同时活跃的变量太多，就需要溢出。溢出会增加加载和存储。

## 条件语句代码生成

三地址码：

```text
if x < y goto L1
goto L2
```

可生成：

```asm
CMP x, y
JL  L1
JMP L2
```

真实机器中还要考虑条件码寄存器、分支预测、延迟槽等机器特性，属于更后面的优化内容。

## 典型题型

1. 给三地址码划分基本块。
2. 构造流图。
3. 根据简单目标机指令生成目标代码。
4. 根据下次引用信息选择寄存器。
5. 解释地址描述符和寄存器描述符。

## 易错点

- 基本块不能有中间入口，也不能有中间跳出。
- 条件跳转后通常有两条出边：真分支和假分支。
- 变量在寄存器中不代表内存中一定是最新值。
- 代码生成依赖中间代码、符号表和运行时布局，不能孤立看。
