# 第 3 章 语法分析

## 学完要会什么

你要能读写上下文无关文法，判断推导、分析树、二义性，能做 LL(1) 预测分析，也能理解 LR/SLR/LALR 分析表的构造思想。

## 上下文无关文法

文法通常写成四元组：

```text
G = (Vn, Vt, P, S)
```

- `Vn`：非终结符集合，如 `Expr`、`Stmt`。
- `Vt`：终结符集合，即 token。
- `P`：产生式集合。
- `S`：开始符号。

例子：

```text
E -> E + T | T
T -> T * F | F
F -> ( E ) | id
```

该文法表达了乘法优先于加法，但有左递归，不适合直接做递归下降。

## 推导、句型、句子、语言

从开始符号反复应用产生式得到的串叫句型；只含终结符的句型叫句子；某文法能生成的全部句子构成该文法的语言。

最左推导每次替换最左非终结符；最右推导每次替换最右非终结符。自顶向下分析通常模拟最左推导，自底向上分析通常反向模拟最右推导。

## 二义性

如果一个句子有两棵不同分析树，或有两个不同最左推导，则文法二义。

典型二义性：

```text
E -> E + E | E * E | (E) | id
```

`id + id * id` 可按先加或先乘解释。解决方法是重写文法，让优先级和结合性体现在文法结构中。

悬空 else 也是经典二义性：

```text
if E then if E then S else S
```

通常规定 `else` 归属于最近的未匹配 `if`。

## 消除左递归

直接左递归：

```text
A -> A alpha | beta
```

可改写为：

```text
A  -> beta A'
A' -> alpha A' | epsilon
```

例如：

```text
E -> E + T | T
```

改为：

```text
E  -> T E'
E' -> + T E' | epsilon
```

## 提左因子

若多个候选式有共同前缀：

```text
A -> alpha beta1 | alpha beta2
```

改为：

```text
A  -> alpha A'
A' -> beta1 | beta2
```

这是为了让自顶向下分析器看较少的输入符号就能决定用哪个产生式。

## FIRST 和 FOLLOW

`FIRST(alpha)`：从 `alpha` 能推出的串的第一个终结符集合；若 `alpha` 能推出空串，则包含 `epsilon`。

`FOLLOW(A)`：在某个句型中可以紧跟在非终结符 `A` 后面的终结符集合。若 `A` 可在句尾，`FOLLOW(A)` 包含输入结束符 `$`。

构造 LL(1) 分析表时：

- 对产生式 `A -> alpha`，把它填入 `M[A, a]`，其中 `a` 属于 `FIRST(alpha)` 且 `a != epsilon`。
- 如果 `epsilon` 属于 `FIRST(alpha)`，则对每个 `b` 属于 `FOLLOW(A)`，把 `A -> alpha` 填入 `M[A, b]`。
- 一个表格项有多个产生式就是冲突，该文法不是 LL(1)。

## 递归下降和预测分析

递归下降为每个非终结符写一个过程。预测分析是非递归版本，用栈和分析表驱动。

预测分析基本过程：

1. 栈初始为 `$ S`，输入末尾加 `$`。
2. 栈顶是终结符时，必须和当前输入匹配。
3. 栈顶是非终结符 `A` 时，用当前输入 token 查 `M[A, token]`。
4. 找到产生式后弹出 `A`，把右部逆序压栈。

## LR 分析

LR 分析从左到右扫描输入，构造最右推导的逆过程。动作包括移进、归约、接受、报错。

LR 项目形如：

```text
A -> alpha . beta
```

点表示已经识别到的位置。

核心函数：

- `closure(I)`：如果项目中点后是非终结符 `B`，则加入 `B` 的所有产生式初始项目。
- `goto(I, X)`：从项目集 `I` 中所有点后为 `X` 的项目出发，把点越过 `X`，再取 closure。

SLR 使用 LR(0) 项目集和 FOLLOW 集决定归约。LR(1) 项目带展望符，能力更强。LALR 合并 LR(1) 中核心相同的项目集，表更小，工具中常用。

## 典型题型

1. 判断某串是否属于某文法。
2. 画分析树，写最左推导或最右推导。
3. 判断文法是否二义。
4. 消除左递归、提左因子。
5. 计算 FIRST/FOLLOW。
6. 构造 LL(1) 预测分析表。
7. 构造 LR(0)/SLR 项目集和分析表，判断冲突。

## 易错点

- `FIRST(A)` 和 `FOLLOW(A)` 不要混。FIRST 看“开头能是什么”，FOLLOW 看“后面能跟什么”。
- `epsilon` 不会进入 FOLLOW 集。
- 消除左递归可能改变分析树形态，但不能改变语言。
- LR 项目集构造时，closure 只对点后是非终结符的项目扩展。
- SLR 归约看 FOLLOW，LR(1) 归约看项目自带展望符。

## 自测清单

- 能否把表达式文法改写成 LL(1) 风格？
- 能否手算 FIRST/FOLLOW？
- 能否解释 LL 和 LR 的方向差异？
- 能否看分析表判断移进/归约冲突？
