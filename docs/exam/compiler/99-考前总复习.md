# 编译原理考前总复习

## 一张总图

```text
源程序
  -> 词法分析：正规式、NFA、DFA、token
  -> 语法分析：CFG、FIRST/FOLLOW、LL、LR、分析树
  -> 语义分析：符号表、作用域、类型检查
  -> 中间代码：三地址码、回填、数组地址、过程调用
  -> 优化：DAG、数据流、活跃变量、到达定值、循环优化
  -> 目标代码：基本块、流图、寄存器、指令选择
  -> 运行：链接、装入、栈、堆、运行时系统
```

## 必背但不要死背的定义

- token：词法记号，通常含种别和属性值。
- 正规式：描述词法模式。
- DFA：确定有限自动机，适合扫描器实现。
- CFG：上下文无关文法，描述程序嵌套结构。
- FIRST：某符号串能推出的开头终结符。
- FOLLOW：某非终结符后面可能出现的终结符。
- 综合属性：从子节点向父节点传。
- 继承属性：从父节点或左兄弟传。
- 活动记录：一次过程调用的运行时栈帧。
- 三地址码：最多两个源地址和一个结果地址的中间代码。
- 基本块：单入口、单出口的顺序代码段。
- 到达定值：某定值能否沿路径到达某点且未被覆盖。
- 活跃变量：变量当前值以后是否可能被使用。

## 高频手算题流程

### token 流

1. 从左到右扫描。
2. 关键字、标识符、常量、运算符、界符分清。
3. 标识符和常量写属性值。

### FIRST/FOLLOW

1. FIRST 先处理终结符和 epsilon。
2. 产生式从左到右看，遇到不能推出 epsilon 的符号就停。
3. FOLLOW 开始符号先放 `$`。
4. `A -> alpha B beta`：把 `FIRST(beta)-epsilon` 加入 `FOLLOW(B)`。
5. 若 `beta =>* epsilon`，把 `FOLLOW(A)` 加入 `FOLLOW(B)`。

### LL(1) 表

1. 对 `A -> alpha`，看 `FIRST(alpha)`。
2. 若含 epsilon，再看 `FOLLOW(A)`。
3. 一个格子多条产生式就是冲突。

### LR 项目集

1. 增广文法。
2. 从 `S' -> .S` 做 closure。
3. 对每个文法符号做 goto。
4. 归约项目按 FOLLOW 或展望符填动作。
5. 检查移进/归约、归约/归约冲突。

### 三地址码

1. 表达式先按语法树顺序生成临时变量。
2. 数组地址记得乘宽度。
3. 布尔表达式优先用短路跳转。
4. 控制流用标签。
5. 过程调用用 `param` 和 `call`。

### 数据流

到达定值：

```text
IN[B]  = union OUT[pred]
OUT[B] = gen[B] union (IN[B] - kill[B])
```

活跃变量：

```text
OUT[B] = union IN[succ]
IN[B]  = use[B] union (OUT[B] - def[B])
```

## 最容易丢分的点

- 把词法错误、语法错误、语义错误混在一起。
- FIRST/FOLLOW 中误把 epsilon 加入 FOLLOW。
- 消除左递归后语言变了。
- LL(1) 表中忘记 epsilon 产生式要按 FOLLOW 填。
- LR closure 忘记对点后的非终结符展开。
- 数组地址计算忘记乘元素宽度。
- 布尔表达式破坏短路语义。
- 死代码删除删掉了有副作用的语句。
- 把动态链和静态链混淆。
- 把 C 的指针传参误认为引用调用。

## 一天速通安排

如果只剩一天：

1. 读 `00`、`01` 建立总图。
2. 精读 `02`、`03`，手算 token、FIRST/FOLLOW、LL(1)、LR 项目。
3. 读 `04`、`05`，理解属性和类型检查。
4. 读 `07`、`09`，练三地址码和数据流方程。
5. 读 `06`、`08`、`11`，把运行时、代码生成和工具链串起来。
6. `10`、`12`、`13` 只看定位和典型题。

## 最小自测卷

1. 写 `int* (*(*b)[10])[10];` 的 token 流并解释类型。
2. 为标识符和浮点数写正规式。
3. 给一个小 NFA，用子集构造法转 DFA。
4. 对表达式文法消除左递归并计算 FIRST/FOLLOW。
5. 构造一个 LL(1) 分析表并指出是否冲突。
6. 给 `while (a<b && c<d) x=x+1;` 写三地址码。
7. 给基本块做 DAG 优化。
8. 给流图写活跃变量方程。
9. 说明递归调用时活动记录中必须保存哪些信息。
10. 说明 `gcc` 从 `.c` 到可执行文件经历哪些阶段。
