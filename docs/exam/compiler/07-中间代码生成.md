# 第 7 章 中间代码生成

## 学完要会什么

你要能把声明、赋值、数组访问、布尔表达式、控制流和过程调用翻译成中间表示，尤其是三地址代码。

## 中间语言的作用

中间表示连接前端和后端。它应当比源语言简单，又不绑定某台机器。

常见中间表示：

- 后缀表示：适合表达式求值。
- 图形表示：语法树、DAG。
- 三地址代码：最常考，也最便于优化和代码生成。
- 静态单赋值形式 SSA：进阶优化常用。

## 三地址代码

三地址代码每条语句最多包含三个地址：两个源操作数和一个结果。

常见形式：

```text
x = y op z
x = op y
x = y
if x relop y goto L
goto L
param x
call p, n
return x
```

表达式：

```c
a = b * -c + b * -c
```

可翻译为：

```text
t1 = -c
t2 = b * t1
t3 = -c
t4 = b * t3
t5 = t2 + t4
a = t5
```

后续优化可发现公共子表达式。

## 声明语句翻译

声明的主要任务是填符号表，计算类型宽度和地址偏移。

例如：

```c
int a;
float b;
int c[10];
```

符号表可记录：

```text
a: type=int, offset=0
b: type=float, offset=4
c: type=array(10,int), offset=8
```

偏移用于后续代码生成。

## 数组地址计算

一维数组 `A[i]` 地址：

```text
base(A) + i * width
```

二维数组按行主序：

```text
A[i][j] = base(A) + ((i * n) + j) * width
```

其中 `n` 是第二维长度。

三地址代码例子：

```text
t1 = i * n
t2 = t1 + j
t3 = t2 * width
x = A[t3]
```

教材和考试常考“数组元素地址计算的翻译方案”。

## 布尔表达式翻译

布尔表达式可翻译成数值，也可直接翻译成控制流。

短路求值很重要：

```c
if (a < b && c < d) S1 else S2
```

翻译思路：

```text
if a < b goto L1
goto Lfalse
L1:
if c < d goto Ltrue
goto Lfalse
Ltrue:
S1
goto Lnext
Lfalse:
S2
Lnext:
```

`&&` 中左边为假时不求右边；`||` 中左边为真时不求右边。

## 控制流语句

`if`、`while`、`for`、`switch` 都可归结为条件跳转和标签。

`while (B) S`：

```text
Lbegin:
  code(B, true=Lbody, false=Lnext)
Lbody:
  code(S)
  goto Lbegin
Lnext:
```

## 回填

生成跳转代码时，目标标签可能还不知道。回填技术先留下空位，等目标确定后统一填入。

常见属性：

- `truelist`：条件为真时待回填的跳转链。
- `falselist`：条件为假时待回填的跳转链。
- `nextlist`：语句执行完后待回填的跳转链。

常用操作：

```text
makelist(i)
merge(p1, p2)
backpatch(p, target)
```

## 过程调用

调用通常翻译为：

```text
param a1
param a2
t = call f, 2
```

编译器还要结合运行时存储布局处理实参求值、参数传递、返回值和调用约定。

## 典型题型

1. 表达式翻译成三地址码。
2. 数组元素访问翻译成地址计算。
3. `if/while` 翻译成带标签三地址码。
4. 布尔表达式短路翻译。
5. 使用回填技术列出 `truelist/falselist/nextlist`。
6. 过程调用翻译。

## 易错点

- 数组地址计算要乘元素宽度。
- 多维数组要明确行主序还是列主序，C 是行主序。
- 布尔表达式不要默认求出 0/1，控制流翻译更常见。
- 回填列表保存的是“尚未知道目标的跳转语句编号”。
