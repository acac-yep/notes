# 第 4 章 语法制导的翻译

## 学完要会什么

你要能给文法符号附加属性，写语义规则，理解 S 属性定义、L 属性定义，能在语法分析过程中构造语法树或生成中间代码。

## 语法制导定义

语法制导定义由文法产生式和语义规则组成。每个文法符号可以带属性，语义规则说明这些属性如何计算。

属性分两类：

- 综合属性：由子节点或自身信息计算，信息自下而上传递。
- 继承属性：由父节点或兄弟节点传入，信息自上而下或横向传递。

例子：

```text
E -> E1 + T
E.val = E1.val + T.val
```

这里 `E.val` 是综合属性。

## 属性依赖图和计算次序

属性之间存在依赖关系。若 `b` 的计算依赖 `c`，则依赖图中有边 `c -> b`。属性计算顺序必须是依赖图的拓扑序。

如果依赖图有环，则属性无法按正常方式求值。

## S 属性定义

只含综合属性的语法制导定义叫 S 属性定义。

它适合自底向上分析，因为归约一个产生式时，右部符号的属性已经算好，可以直接计算左部属性。

例子：

```text
L -> E \n     print(E.val)
E -> E1 + T  E.val = E1.val + T.val
E -> T       E.val = T.val
T -> num     T.val = num.lexval
```

## L 属性定义

L 属性定义允许继承属性，但有约束：产生式 `A -> X1 X2 ... Xn` 中，`Xi` 的继承属性只能依赖：

- `A` 的继承属性。
- `Xi` 左边符号 `X1 ... Xi-1` 的属性。

这保证自顶向下或深度优先遍历时能计算。

## 翻译方案

翻译方案把语义动作嵌入产生式右部。动作出现的位置决定执行时机。

例如构造后缀式：

```text
E -> E1 + T { print('+') }
E -> T
T -> num { print(num.lexval) }
```

输入 `3 + 4` 输出 `3 4 +`。

## 构造语法树

抽象语法树会省略不影响语义的语法细节，如括号、分号、某些中间非终结符。

表达式：

```text
a + b * c
```

抽象语法树可理解为：

```text
    +
   / \
  a   *
     / \
    b   c
```

乘法成为加法右子树，体现优先级。

## 典型应用

语法制导翻译可用于：

- 计算表达式值。
- 构造抽象语法树。
- 生成三地址码。
- 填写类型信息。
- 回填跳转地址。
- 管理符号表作用域。

## 典型题型

1. 给定语法制导定义，计算某输入串的属性值。
2. 判断某属性定义是否为 S 属性或 L 属性。
3. 画属性依赖图，给出计算顺序。
4. 在产生式中嵌入动作，生成后缀式或三地址码。
5. 给表达式构造语法树。

## 易错点

- 继承属性不是“只能从父亲来”，也可以从左兄弟来。
- S 属性定义一定是 L 属性定义的特例。
- 翻译方案中动作位置很重要，放在右部不同位置会改变执行时机。
- 语法树不等于抽象语法树。抽象语法树更接近语义结构。
