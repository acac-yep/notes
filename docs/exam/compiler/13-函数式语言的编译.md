# 第 13 章 函数式语言的编译

## 学习定位

本章是扩展章节。若时间有限，掌握函数式语言和命令式语言在运行时上的关键差异即可：函数是一等值，变量绑定更强调不可变，闭包和环境是核心。

## 函数式语言特点

函数式语言常见特征：

- 函数是一等值，可以作为参数、返回值、变量值。
- 变量绑定通常不可变。
- 递归比循环更常见。
- 高阶函数常见。
- 闭包用于保存函数及其自由变量环境。

## 自由变量和约束变量

在表达式中，由某个绑定结构引入的变量叫约束变量；没有在当前表达式内绑定的变量叫自由变量。

例子：

```text
lambda x. x + y
```

`x` 是约束变量，`y` 是自由变量。若这个函数被返回到外部，仍需要记住 `y` 的值或位置，这就是闭包要解决的问题。

## 闭包

闭包 = 代码指针 + 环境。

```text
closure = (function_code, environment)
```

环境保存自由变量绑定。

例如：

```text
makeAdder(y) = lambda x. x + y
```

调用 `makeAdder(10)` 返回的函数必须携带 `y=10`，否则以后执行 `x + y` 找不到 `y`。

## 抽象机

函数式语言编译常用抽象机模型解释执行和运行时结构，例如控制栈、环境、堆上的闭包等。

抽象机不一定是真实硬件，而是方便定义语言执行规则的目标模型。

## 指令集和编译

函数式语言编译器需要处理：

- 表达式求值。
- 函数定义和应用。
- 环境建立。
- 闭包构造。
- 变量寻址。
- 尾调用优化。

尾调用优化很重要：若函数最后一步是调用另一个函数，则可复用当前栈帧，避免递归过深。

## 典型题型

1. 判断自由变量和约束变量。
2. 解释闭包为什么需要环境。
3. 说明函数作为返回值时运行时要保存什么。
4. 解释尾调用优化的意义。

## 易错点

- 函数值不只是代码地址，还可能需要环境。
- 自由变量不是全局变量，它只是没有在当前函数内部绑定。
- 闭包环境保存的是函数执行所需的外部绑定。
- 尾递归可优化成类似循环，但前提是递归调用在尾位置。

## 自测清单

- 能否找出 `lambda x. lambda y. x + y + z` 中每层的自由变量？
- 能否解释 `makeAdder` 为什么返回闭包？
- 能否说明尾调用为什么能复用栈帧？
